研討會場地最常見的失誤，不是選得太小，而是**用錯的方式估容量**。

場地標示「可容納 60 人」，你報名了 55 個人，覺得剛好。到了現場才發現：那 60 人是**劇院式**（只放椅子）的極限值，而你的活動要做筆記，得用教室式——實際只坐得下 28 個。

這篇按照場勘的順序，把該確認的事整理成可以照著跑的檢查表。

## 研討會場地要看的第一件事是什麼？

**不是坪數，是動線。**

坪數決定「塞不塞得下」，動線決定「順不順」。而參加者對一場活動的印象，多半在報到那三分鐘就決定了。

要看的四段動線：

1. **從大門到報到桌** —— 有沒有指標？會不會走錯樓層？
2. **報到後到座位** —— 報到完的人會不會擋住後面的人？
3. **中場休息** —— 洗手間在哪？四十個人十分鐘內夠不夠用？
4. **散場** —— 電梯載得動嗎？會不會全部堵在一樓大廳？

> 🔑 **會塞車的不是空間，是轉折點。** 門口、報到桌、電梯口——這三個地方只要有一個設計不良，整場活動的體感就會變差。

## 人數怎麼抓？

**不要直接用報名人數決定場地大小。**

| 活動類型 | 實到率 | 怎麼抓 |
|---|---|---|
| 免費、線上報名 | 明顯偏低 | 用報名數的一定比例估，但場地仍要留餘裕 |
| 付費活動 | 接近報名數 | 用報名數抓 |
| 邀請制、企業內訓 | 幾乎全到 | 用名單抓 |

實務上的做法是**抓一個區間**：

```
場地大小  → 用實到的「高標」決定（寧可大，不要擠）
餐飲數量  → 用實到的「低標」決定（吃不完就是浪費）
```

⚠️ **場地標示的「可容納人數」幾乎都是劇院式的極限值。** 換桌型就要重算。

## 桌型怎麼選？它會直接決定你要多大的場地

| 桌型 | 容納人數 | 適合 | 缺點 |
|---|---|---|---|
| **劇院式**（只有椅子）| 最多 | 單向演講、發表會 | 不能做筆記、不好互動 |
| **教室式**（有長桌）| **約劇院式的一半** | 教學、訓練、要抄筆記 | 佔空間 |
| **U 型** | 少 | 討論、工作坊 | 人一多就聽不到 |
| **圓桌** | 少 | 分組討論、餐會 | 有人會背對講台 |
| **站立式** | 多 | 交流、酒會 | 不適合長時間 |

**選桌型不是美觀問題，是空間問題。** 決定內容形式的同時，場地需求就已經決定了。

## 「有投影機」不等於你接得上

**設備一定要現場測，不要相信清單。**

場勘時帶自己的筆電，實際做這五件事：

| 測什麼 | 為什麼 |
|---|---|
| **投影一次** | 接頭是 HDMI 還是 Type-C？要不要轉接？ |
| **播一段有聲音的影片** | 音源要另外接線，這是最常漏的 |
| **測網路速度** | 「有 Wi-Fi」不等於四十人同時連得動 |
| **麥克風講一句話** | 有沒有回音？後排聽不聽得到？ |
| **找插座** | 位置在哪、夠不夠、要不要延長線 |

> 最常出事的是**音源**。投影通了、畫面出來了，影片一播才發現沒有聲音——而那時候台下已經坐滿人。

## 報到與動線怎麼安排

三個實務原則：

1. **報到桌側放，不要正對入口** —— 讓報到完的人能直接往內走
2. **每一百人至少兩個報到位置** —— 一個位置處理不了尖峰
3. **門口留緩衝空間** —— 隊伍不要排到電梯或樓梯口

另外準備一份**紙本名單**。系統當機、網路斷線的時候，紙本是唯一還能運作的東西。

## 茶水與餐點

半天以內：**準備飲用水就夠**。

跨越用餐時間：要考慮餐盒或附近餐飲。但重點不是豐盛，是**有沒有地方吃**——

> 場地如果沒有可以放餐點與垃圾的區域，四十個人在座位上吃便當，收拾會是一場災難，而且清潔費可能另計。

## 場勘檢查表

去現場時帶著這張表，逐項打勾：

**空間**
- [ ] 實際坪數與可用範圍（扣掉柱子、走道）
- [ ] 天花板高度（會不會壓迫）
- [ ] 採光與遮光（投影時能不能拉窗簾）
- [ ] 空調（滿座時夠不夠冷）
- [ ] 噪音（隔壁在做什麼）

**設備**
- [ ] 投影／螢幕，實測接得上
- [ ] 音響與音源線，實測有聲音
- [ ] 麥克風支數與型式
- [ ] 網路實測速度
- [ ] 插座位置與數量

**動線**
- [ ] 大門到報到桌的指標
- [ ] 報到區空間
- [ ] 洗手間位置與數量
- [ ] 電梯數量與載客量
- [ ] 停車位

**行政**
- [ ] 進場布置可以提早多久
- [ ] 撤場要在幾點前完成
- [ ] 可不可以張貼指示牌、貼在哪
- [ ] 現場有沒有人可以協助
